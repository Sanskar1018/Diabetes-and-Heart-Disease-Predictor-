
# Multi_disease_model

# 🩺 Diabetes and Heart Disease Predictor 2025

A machine learning project that predicts **Diabetes** and **Heart Disease** risks using two distinct algorithms for enhanced accuracy.

## 🚀 Project Overview
- **Diabetes Prediction**: Implemented using **Support Vector Classifier (SVC)** for robust and reliable results.  
- **Heart Disease Prediction**: Implemented using **Gradient Boosting** for accurate risk assessment.  

This project demonstrates how different ML algorithms can be applied to separate but related health prediction tasks.

## 📂 Features
- Dual-purpose predictive system (Diabetes + Heart Disease).  
- Clean and modular Python code.  
- Jupyter Notebook for experiments and visualization.  
- Uses publicly available medical datasets.  

## 🛠️ Tech Stack
- Python  
- Scikit-learn  
- Pandas, NumPy  
- Matplotlib, Seaborn  

## 📊 Model Performance
- **SVC** performed strongly for diabetes classification.  
- **Gradient Boosting** provided superior results for heart disease risk prediction.
